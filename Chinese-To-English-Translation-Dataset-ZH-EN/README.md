# Chinese-to-English Translation Dataset (ZH→EN)

A Chinese-to-English translation dataset designed for travel and tourism scenarios, providing paired Chinese source text and corresponding English translations to support multilingual training and cross-lingual understanding. Built on text modality, it is well suited for aligning and delivering multilingual information in real-time sightseeing crowd guidance. Common applications include machine translation, translation quality evaluation, and bilingual semantic modeling, especially for pretraining/multilingual pretraining workflows.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| source_text | string | The Chinese text that needs to be translated. |
| translated_en | string | The English text translated from the corresponding Chinese source. |
