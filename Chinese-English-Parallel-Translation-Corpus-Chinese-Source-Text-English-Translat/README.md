# Chinese-English Parallel Translation Corpus (Chinese Source Text & English Translation)

A Chinese–English parallel corpus resource for translation and cross-lingual alignment applications, providing one-to-one bilingual text pairs: Chinese source texts aligned with their corresponding English translations. The data covers common writing styles and domains, making it suitable for parallel alignment, translation modeling, and cross-lingual representation learning.
It supports downstream tasks ranging from sentence/line alignment to multilingual pretraining and continued training. The corpus can improve machine translation quality, translation quality estimation, and consistency in cross-lingual retrieval and aligned representations. It is also useful for building training and evaluation splits for modeling workflows.
Delivery typically includes data cleaning and quality control (e.g., deduplication, length/noise filtering, alignment consistency checks, and character/encoding normalization) to reduce mismatches and the impact of low-quality samples.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| source_text | string | The input Chinese source text used as the translation input. It serves as the source side for bilingual sentence/line alignment. |
| translated_text | string | The English translation corresponding to each Chinese source text. It serves as the target side for parallel alignment and translation modeling. |
