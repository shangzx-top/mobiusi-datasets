# Chinese-English Translation Corpus (Chinese–English)

A Chinese–English translation corpus designed for cross-lingual cultural research and natural language processing, providing paired bilingual text for parallel alignment and translation modeling. The collection covers a range of common language styles and domains, supporting workflows from sentence-level alignment to multilingual pretraining and continued training. Ideal for machine translation, translation quality estimation, cross-lingual search, and alignment representation learning to improve model generalization across Chinese and English.

## Technical Specifications

| Field | Type | Description |
| :---  | :---  | :--- |
| source_text | string | 输入的中文文本原文（作为翻译源）。 |
| translated_text | string | 中文原文对应的英文翻译结果。 |
